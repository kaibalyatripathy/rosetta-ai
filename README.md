# Rosetta AI

## Problem Statement
Rosetta AI is an automated code translation and benchmarking framework designed to seamlessly convert code across programming languages (Python, Java, C++, JavaScript) while maintaining semantic equivalence and enabling evaluation across various LLM backends.
