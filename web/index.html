📖 Canonical Algorithm Benchmarks

DYNAMIC PROGRAMMING

Kadane's Algorithm (Maximum Subarray)

Computes the contiguous subarray within a one-dimensional numeric array that has the largest sum in linear time.

Time Complexity: $O(n)$ Space Complexity: $O(1)$ 
max_current = max_global = arr[0]
for num in arr[1:]:
    max_current = max(num, max_current + num)
    max_global = max(max_global, max_current)
return max_global
⚠️ Cross-Language Hazard: Negative integer indexing or initialization with 0 instead of arr[0] causes failures on all-negative arrays.
NUMBER THEORY

Euclidean GCD (Greatest Common Divisor)

Efficient method for computing the greatest common divisor of two integers based on the principle that the GCD of two numbers also divides their difference.

Time Complexity: $O(\log(\min(a, b)))$ Space Complexity: $O(1)$ 
while b != 0:
    a, b = b, a % b
return a
⚠️ Cross-Language Hazard: Truncated modulo behavior on negative values in C++/Java vs floored modulo in Python.
DIVIDE & CONQUER

Binary Search

Locates the position of a target value within a sorted array by repeatedly dividing the search interval in half.

Time Complexity: $O(\log n)$ Space Complexity: $O(1)$ 
while left <= right:
    mid = left + (right - left) // 2
    if arr[mid] == target: return mid
    elif arr[mid] < target: left = mid + 1
    else: right = mid - 1
return -1
⚠️ Cross-Language Hazard: (left + right) / 2 overflows 32-bit signed integers in C++/Java when arrays exceed $2^{30}$ elements.
SEMANTIC RISK TRAP

Recursive Factorial

Calculates the product of all positive integers less than or equal to $n$. Canonical benchmark for arbitrary precision vs fixed-width integer limits.

Time Complexity: $O(n)$ Space Complexity: $O(n)$ Stack 
def factorial(n):
    if n <= 1: return 1
    return n * factorial(n - 1)
⚠️ Cross-Language Hazard: Python integers have infinite precision. Translating $n=50$ to 32-bit Java int overflows into negative garbage at $n \ge 13$.

2. Differential Testing Formulation

For any algorithm f and test vector input sequence X = {x₁, x₂, ..., xₖ}, the verification engine enforces strict equivalence:

∀ xᵢ ∈ X : Norm(Exec(fsource, xᵢ)) ≡ Norm(Exec(ftarget, xᵢ))

Normalization strips trailing whitespaces, unifies floating-point precision (ε < 10⁻⁶), and unpacks serialized arrays across standard output streams.
